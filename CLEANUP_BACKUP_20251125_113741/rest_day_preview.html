Technical Details

  • • data-schedule-id: "rest_day"
  • • work_schedule_id field: Empty/NULL when rest day selected
  • • Database: work_schedule_id = NULL in post_schedule_change_requests table
  • • Color Theme: Red (#ef4444) to distinguish from work schedules
  • • Form Validation: Accepts empty work_schedule_id
