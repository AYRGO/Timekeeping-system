📅 Daily Schedule Cache System Setup

Problem: Calendars showing "No schedule" for all dates

Solution: Create pre-computed schedule cache for past, present, and future dates

⚠️ Important: Run these steps in order. Each step depends on the previous one.

📋 Setup Steps

Step 1: Setup Weekly Default Schedules

Creates recurring Mon-Fri work schedules for all employees based on their official_sched field.

  • Sets Mon-Fri to employee's assigned work schedule
  • Sets Sat-Sun as rest days
  • Stores in employee_default_schedules table
🚀 Run Step 1

Step 2: Create Cache System

Creates the cache table, stored procedures, triggers, and populates all schedule data.

  • Creates employee_daily_schedule_cache table
  • Creates stored procedures for population
  • Creates triggers for auto-updates
  • Populates 6 months back to 12 months forward
  • Sets up daily maintenance event
🔧 Run Step 2

Step 3: Verify Setup

Check that everything is working correctly.

  • View schedule data for employees
  • See cache statistics
  • Test priority system
  • View sample schedule data
📊 Check Data

💡 How It Works

Old System: Complex priority-based lookups every time calendar loads

New System: One simple query to pre-computed cache table

Schedule Priority (automatic):

  1. Approved schedule change requests
  2. Admin daily overrides
  3. Weekly default schedule
  4. Company holidays
  5. Weekend fallback

Example Query:

SELECT schedule_name, time_in, time_out, is_rest_day, is_holiday
FROM employee_daily_schedule_cache
WHERE employee_id = 1 AND schedule_date = '2025-10-22';
