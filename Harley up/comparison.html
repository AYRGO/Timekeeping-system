📊 Admin Dashboard

The admin dashboard is the central hub for managing all employee requests and schedules.

  • Renamed "Current Requests" to "Single Request": More accurately describes pending individual schedule change requests
  • Pagination Added (10 per page): All request tabs now support pagination for better performance with large datasets
  • Pending Requests Prioritized: Approved and declined requests moved to next pages; pending requests shown first
  • Unified Badge Counter: Sidebar badge now sums all pending requests across Single Request, Monthly Schedule, and Swap Request tabs
  • Cleaner Layout: Removed redundant information for a more focused user experience
✅ Improvements: Better organization of request management, faster loading times, clearer priority visibility, centralized pending count.

📅 Schedule Change Request Form

The schedule change request form allows employees to submit requests to change their work schedules.

  • Removed Green Selection Display: The redundant green highlight for selected schedules has been removed
  • Month Input Placeholder: Added clear "Please Choose Month" placeholder text for better UX
  • Month Selection Highlighting: When a month is selected, it now highlights with a visual indicator
  • Cleaner Form Layout: More intuitive form structure with better visual hierarchy
  • "Less is More" Design Philosophy: Removed verbose text like "Default Schedule", duration breakdowns, and outdated information
  • Simplified Request Status: Changed "Request Expired (30+ days old)" to simply "Request Expired"
🎨 Design Focus: Emphasis on clarity and simplicity while maintaining full functionality.

🚀 System-Wide Improvements

🔄 Auto-Forfeit System

Automatically marks requests as "Forfeited" if they remain pending past the current date. Implemented with Windows Task Scheduler for reliable daily execution.

📅 Historical Schedule Editing

Administrators can now edit past schedules in the calendar history. Previously restricted date editing has been removed to allow full schedule management flexibility.

⏰ Smart Overtime Calculation

Overtime display now reflects the actual work schedule from the calendar. RDOT (Rest Day OT) is automatically detected and calculated when overtime occurs on a rest day (time in to time out).

🎯 Conflict Resolution

When a monthly schedule change is approved, any pending swap requests or single schedule change requests that conflict are automatically cancelled to prevent scheduling conflicts.

✉️ Email Encoding Fix

Fixed emoji characters displaying as garbled text (ðŸ"…) in email notifications. All emojis removed from HTML email templates for proper UTF-8 encoding and professional appearance.

💾 Database Updates

Updated database schema with new status options (Cancelled, Forfeited). Fixed column errors and JSON parsing issues for improved data integrity.

🎨 UI Simplification

Applied "less is more" principle across all screens. Removed verbose text labels, unnecessary duration breakdowns, and redundant information for a cleaner, more professional appearance.

📱 Pagination System

Implemented 10-records-per-page pagination with pending-first sorting across all request tabs. Improves performance and makes data browsing more manageable.
