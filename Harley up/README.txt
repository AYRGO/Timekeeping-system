📜 ATTENDANCE HISTORY
   • Daily records from July 1, 2025 onwards
   • 5 status categories:
     - Complete: Full shift worked
     - Late: Clocked in after scheduled time
     - Undertime: Left before scheduled time
     - Leave: Approved leave day
     - Incomplete: Missing clock in/out
   • Search and filter functionality
   • Time adjustment tracking

⚡ OVERTIME REQUESTS
   • NDOT: Normal day overtime
   • RDOT: Rest day overtime (auto-detected)
   • Hours and minutes input (e.g., 2 hrs 30 mins)
   • Client approval attachment required
   • Reason for overtime required
   • Edit hours before approval
   • Calculates from Start OT to End OT

📆 SCHEDULE CALENDAR
   • Complete monthly schedule view
   • Color-coded working/rest days
   • Time windows and OT availability
   • Active schedule section
   • Must be set up for OT accuracy
   • Foundation for all calculations

📅 MONTHLY SCHEDULE REQUESTS
   • Change entire month at once
   • Day-by-day schedule selection
   • Include rest days for month
   • Client documentation required
   • Immediate approval application
   • Auto-cancels conflicting requests

📆 SINGLE DAY SCHEDULE REQUESTS
   • Change one specific date
   • Different work shift for one day
   • Requires attachment and reason
   • Fast approval process
   • Track in Recent Activities

🛏️ DAY OFF / REST DAY REQUESTS
   • Request a day off from work
   • Different from Leave Requests
   • Single date selection
   • Requires reason and documentation
   • Changes date to rest day

🔄 SCHEDULE SWAP REQUESTS
   • Swap schedules between two dates
   • Same month only
   • Both dates must be future dates
   • Visual swap comparison
   • Perfect for flexible rearrangement
