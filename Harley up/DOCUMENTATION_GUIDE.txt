FEATURES DOCUMENTED IN EMPLOYEE MANUAL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. RECENT ACTIVITIES DASHBOARD
   - View all pending requests (Leave, Schedule, Time, OT)
   - Edit pending requests without resubmitting
   - Cancel requests directly
   - Manage attachments (upload/download/delete)
   - See detailed request information

2. ATTENDANCE HISTORY
   - Daily attendance records from July 1, 2025 onwards
   - 5 Status Types:
     ✓ Complete - Full shift worked
     ✓ Late - Clocked in after scheduled time
     ✓ Undertime - Left before scheduled time
     ✓ Leave - Approved leave day
     ✗ Incomplete - No clock in/out
   - Search and filter functionality
   - Time adjustment tracking

3. OVERTIME REQUESTS
   - NDOT (Normal Day OT) - Regular day overtime
   - RDOT (Rest Day OT) - Auto-detected on rest days
   - Hours and minutes input (e.g., 2 hrs 30 mins)
   - Client approval attachment required
   - Reason for overtime required
   - Edit hours before approval
   - Tracks from Start OT to End OT time windows

4. SCHEDULE CALENDAR
   - Complete monthly view of your schedule
   - Color-coded working days, rest days, special schedules
   - Shows time windows and OT availability
   - Active schedule section showing current times
   - Foundation for accurate OT and day-off calculations
   - Must be set up properly BEFORE requesting OT/changes

5. MONTHLY SCHEDULE REQUESTS
   - Change entire month's schedule at once
   - Day-by-day schedule selection
   - Include rest days for the entire month
   - Submit with client documentation
   - Approval applies schedule immediately
   - Automatically cancels conflicting pending requests

6. SINGLE DAY SCHEDULE REQUESTS
   - Change one specific date's schedule
   - Different work shift for one day
   - Requires attachment and reason
   - Fast approval process
   - Track in Recent Activities

7. DAY OFF / REST DAY REQUESTS
   - Request a day off from work
   - Different from Leave Requests
   - Single date selection
   - Requires reason and documentation
   - Changes that date to a rest day

8. SCHEDULE SWAP REQUESTS
   - Swap schedules between two dates
   - Both dates must be in same month
   - Both dates must be in future
   - Violet/purple swap icon on calendar
   - Shows side-by-side schedule comparison
   - Perfect for flexible rearrangement

   - Automatically marks old pending requests as "Forfeited"

   - Automatically identifies Rest Day OT

   - Better schedule management flexibility

   - Better performance with large datasets
