📅 Employee Schedule Import Tools

📊 What this does:
  • ✓ Imports 90+ employee weekly default schedules directly into database
  • ✓ Generates calendar cache for next 6 months automatically
  • ✓ No manual schedule entry needed - all done programmatically!
⚠️ Important: Make sure XAMPP MySQL is running before proceeding.

Step 1: Import Employee Schedules

This will import weekly default schedules for all 90+ employees from the provided data list.

What happens:

  • Reads employee names and schedule patterns
  • Finds each employee in database
  • Inserts weekly schedule (Mon-Sun) into employee_default_schedules table
  • Shows success/error count for each employee
🚀 Run Schedule Import

Step 2: Generate Schedule Cache (Calendar Entries)

After importing schedules, run this to generate daily calendar entries for the next 6 months.

What happens:

  • Reads weekly default schedules from Step 1
  • Generates daily entries in employee_daily_schedule_cache table
  • Creates entries from today to +6 months
  • Populates employee calendar system automatically
📆 Rebuild Schedule Cache

Step 3: Verify Results

Check employee calendars to confirm schedules are showing correctly.

Database Table Structure Info

employee_default_schedules

  • employee_id - FK to employees table
  • day_of_week - 0 (Sun) to 6 (Sat)
  • work_schedule_id - FK to work_schedules table
  • is_rest_day - 1 = OFF day, 0 = working day

employee_daily_schedule_cache

  • employee_id - FK to employees table
  • schedule_date - specific date (YYYY-MM-DD)
  • work_schedule_id - FK to work_schedules table
  • schedule_name - cached schedule name
  • time_in / time_out - cached times
💡 Pro Tip: After import, you can still manually adjust individual employee schedules through the employee edit page's calendar tab. The import just sets the default weekly patterns.
